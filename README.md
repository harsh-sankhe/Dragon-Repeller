# Dragon Repeller

A small browser RPG. You start in a town with 50 gold and a stick, and a dragon is stopping everyone from leaving. Buy better weapons, grind some monsters in the cave, and take it down.

**Play it here:** [YOUR-VERCEL-LINK](YOUR-VERCEL-LINK)

## How to play

- Use the three buttons under the scene to move around and fight. On a keyboard you can press 1, 2 and 3 instead.
- **Store:** 10 gold buys 10 health (max 100), 30 gold buys the next weapon. Once you own the best weapon you can sell your old ones for 15 gold each.
- **Cave:** fight a slime or a fanged beast to earn XP and gold.
- **Dragon:** fight it from the town square when you feel ready.
- Weapons can break after a hit (about a 1 in 10 chance), so don't sell your backup too early.
- After winning a fight there's a secret number game you can try for a little extra gold.

| Weapon | Power |
| --- | --- |
| Stick | 5 |
| Dagger | 30 |
| Spear | 50 |
| Sword | 100 |

| Monster | Health |
| --- | --- |
| Slime | 15 |
| Fanged beast | 60 |
| Dragon | 300 |

## Run it locally

No install or build step. Download the project and open `index.html` in your browser.

## Files

```
index.html   page structure
styles.css   layout, scenes and animations
script.js    game logic and the character artwork
```

## Built with

Plain HTML, CSS and JavaScript. All the characters, weapons and backgrounds are drawn in code (SVG and CSS), so there are no image files. Works on both desktop and mobile.
